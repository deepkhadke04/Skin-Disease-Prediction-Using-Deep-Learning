# Skin Disease Prediction Using Deep Learning

## Overview
This project is an Android-based application that predicts skin diseases using image classification powered by deep learning.

A Convolutional Neural Network (CNN) model is used to analyze skin images and predict possible skin conditions.

## Problem Statement
Early detection of skin diseases can help in faster treatment. This application assists users by analyzing skin images and predicting possible conditions using AI.

## System Workflow

User Image → CNN Model → Prediction Result

## Features
- Image-based disease detection
- Deep learning classification model
- Mobile application interface
- Automated disease prediction

## Model Architecture
The system uses a Convolutional Neural Network (CNN) for image classification.

Key components:
- Image preprocessing
- Feature extraction using convolution layers
- Classification using neural network layers

## Application Workflow
1. User uploads an image of skin condition
2. Image is processed by the trained CNN model
3. Model predicts the disease category
4. Result is displayed to the user
